## 🔑 Key Concepts

### Cache System
- **What:** Streamlit stores data in memory for 5 minutes
- **Why:** Improves performance, reduces database queries
- **Control:** Click 🗑️ button to clear and reload instantly
- **Status:** See 📂 (CSV) or ⚠️ (SQL) box to know source

### Data Sources
- **Priority 1:** CSV files in SharePoint folder
- **Priority 2:** SQL Server database (fallback)
- **Control:** Upload CSV to use, delete to use SQL

### Pages
- **Main:** Dashboard with cache controls
- **GPS Team:** Staff members list
- **GPS Incidents:** Incident analytics
